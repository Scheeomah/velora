VÉLORA – Unisex Fashion E-commerce Website

VÉLORA is a modern, premium unisex fashion e-commerce website designed to deliver a seamless and elegant online shopping experience. It features curated fashion collections for men and women, interactive product browsing, a shopping cart, checkout experience, and an AI-powered styling assistant.

Built with Next.js, React, JavaScript, and Tailwind CSS, VÉLORA combines contemporary design with interactive shopping features and a clean, responsive interface.

Key Features
- Responsive and modern fashion storefront
- Product catalogue with category filters
- Shopping cart and checkout flow
- AI Stylist interface for personalised fashion recommendations
- Dedicated contact page and WhatsApp integration
- Premium editorial-inspired UI design
